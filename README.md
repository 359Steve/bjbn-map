# Branch Canvas (柳枝背景插件)

一个基于 **Vue 3** 的轻量级柳枝背景插件，可以轻松在网页或组件中生成飘动的柳枝背景效果，适合用于网站、博客、活动页面等场景，增加自然灵动的视觉感。

---

## 🌿 特性

- 基于 **Vue 3 + Canvas** 实现
- 可自定义柳枝数量、长度、颜色和摆动幅度
- 支持 **响应式布局**，自动适应容器大小
- **轻量化**，无第三方依赖（仅依赖 Vue）
- 支持 **ESM / UMD** 模块模式，可 CDN 引入

---

## ⚡ 安装

使用 npm:

```bash
npm install branch-canvas
```
